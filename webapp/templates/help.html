Nápověda – EasyFlex Web

Průvodce, jak využít všechny funkce aplikace od prvního přihlášení až po export do ABRA Gen.

Rychlý start

  1. Přihlaste se a otevřete Nastavení → vyplňte svůj OpenAI API klíč a údaje k ABRA Gen.
  2. V sekci Kredity zkontrolujte zůstatek (noví uživatelé začínají se 100 kredity). Jeden kredit = zpracování jedné faktury.
  3. V Nahrát PDF nahrajte jedno nebo více PDF. Před odesláním zkontrolujte, že máte dostatek kreditů.
  4. Po zpracování zkontrolujte výsledek na kartě Výsledky a upravte případné chybějící údaje.
  5. Označte řádky pro import a dokončete převod do ABRA pomocí tlačítka Importovat do ABRA.

Podrobný průvodce

Nastavení

  • OpenAI API klíč: nutný pro extrakci dat z PDF.
  • ABRA připojení: host, port, firma, uživatel a heslo – bez nich nelze importovat.
  • Typy dokladů a společnosti: předvyplňte je, aby se při importu nabízely správné hodnoty.

Kredity

  • 1 kredit = zpracování 1 faktury (prázdné výsledky se neúčtují).
  • Platby: bankovní převod (CZK). QR kód a variabilní symbol najdete v sekci Kredity.
  • Minimální dobití: 100 Kč (200 kreditů).

Nahrávání PDF

  • Můžete nahrát jednotlivé soubory nebo složku s více PDF.
  • Nepodporované formáty se automaticky přeskočí a zobrazí se upozornění.
  • Po nahrání dostanete přehled faktur; můžete ručně opravit čísla dokladů, datumy nebo částky.

Import do ABRA

  • Před importem vyberte firmu, směr a typ dokladu.
  • Řádky lze označit/odznačit pro import; chybné řádky se dají opravit a import zopakovat.
  • Log s chybami (např. špatné IČ/DIČ) se zobrazí přímo u řádku.

Časté otázky

Nenačítá se mi QR kód pro platbu, co dělat?
Zkontrolujte, zda jste přihlášeni. QR kód je dostupný jen po přihlášení v sekci Kredity. Pokud problém přetrvá, napište nám.
Nemám dostatek kreditů, ale potřebuji rychle zpracovat faktury.
Dočasně odeberte některé PDF a spusťte zpracování menšího počtu souborů. Současně můžete dobít kredity převodem (zobrazí se variabilní symbol).
Import do ABRA hlásí chybu ověření.
Ověřte přihlašovací údaje v Nastavení a že je správně zvolená firma i typ dokladu. Pokud používáte vlastní certifikát, ujistěte se, že je server dostupný a akceptuje TLS.
Co se stane, když je faktura prázdná nebo nečitelná?
Prázdné výsledky neodečítají kredity. Pokud je text nečitelný, zkuste lepší sken nebo kontaktujte podporu.
Jak funguje označování řádků pro import?
Každý řádek má přepínač. Jen označené řádky se odešlou do ABRA. Před importem můžete hodnoty upravit a změny uložit.

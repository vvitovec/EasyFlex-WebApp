Nápověda – EasyFlex Web

Průvodce, jak využít všechny funkce aplikace od prvního přístupu až po import do ABRA Flexi.

Rychlý start

  1. Založení účtu a reset hesla probíhá výhradně přes podporu: napište na {{ contact_email }} nebo volejte {{ contact_phone }}.
  2. Přihlaste se a v sekci Kredity zkontrolujte zůstatek (noví uživatelé startují se 100 kredity). Minimální dobití je 100 kreditů za 50 Kč podle údajů v sekci Kredity.
  3. V Nastavení → karta ABRA vyplňte adresu a port instance ABRA Flexi, uživatelské jméno a heslo. Podle vašeho serveru zapněte/vypněte ověřování TLS.
  4. V kartě Import do ABRA předvyplňte firmy a typy dokladů podle návodu níže, aby se při importu nabízely správné hodnoty.
  5. V Nahrát PDF nahrajte jedno nebo více PDF a spusťte zpracování (1 kredit = 1 faktura; prázdné/neúspěšné extrakce se neúčtují).
  6. Po zpracování otevřete Výsledky, zkontrolujte a případně upravte data a dokončete import do ABRA Flexi.

Podrobný průvodce

Registrace a přístup

  • Registrace, aktivace i reset hesla řeší administrátor na {{ contact_email }} nebo {{ contact_phone }}.
  • Přihlašovací údaje obdržíte od administrátora. Pokud se nemůžete přihlásit, napište nebo zavolejte – samoobslužné obnovení hesla není dostupné.

Nastavení

  • ABRA: zadejte adresu/hostitele a port vaší instance ABRA Flexi, uživatele a heslo pro REST API. Volba ověřování TLS odpovídá tomu, zda server používá platný certifikát.
  • Extractor: vidí pouze administrátor a spravuje zde OpenAI klíč a model. Běžný uživatel nic nevyplňuje.
  • Extrakce: přepínače pro použití čísla dokladu jako VS, dopočítávání chybějících dat, mapování CSV sloupců a auto-import po extrakci.
  • Import do ABRA: přidejte firmy a typy dokladů, aby se při importu nabízely správné kombinace pro vaši instanci.

Kredity

  • 1 kredit = zpracování 1 faktury (prázdné výsledky se neúčtují). Noví uživatelé začínají se 100 kredity.
  • Platby: bankovní převod (CZK). QR kód a variabilní symbol najdete v sekci Kredity; kredity připisuje ručně administrátor.
  • Minimální dobití: 100 kreditů za 50 Kč. Potřebujete-li více, zadejte vyšší částku při platbě.

Nahrávání PDF a extrakce

  • Můžete nahrát jednotlivé soubory nebo složku s více PDF.
  • Nepodporované formáty se automaticky přeskočí a zobrazí se upozornění.
  • Po nahrání dostanete přehled faktur; můžete ručně opravit čísla dokladů, datumy, částky nebo identifikaci dodavatele/odběratele.

Import do ABRA Flexi

  • Před importem vyberte firmu, směr a typ dokladu z hodnot, které jste si nastavili v části Import do ABRA.
  • Řádky lze označit/odznačit pro import; chyby (např. neplatné IČ/DIČ nebo kód dokladu) se zobrazí přímo u řádku.
  • Po opravě dat můžete import zopakovat; úspěšně importované řádky se označí jako hotové.

Přidávání firem a typů dokladů pro ABRA Flexi

Vše se nastavuje v části Nastavení → Import do ABRA. Správné kódy přebíráme přímo z ABRA Flexi, proto je potřeba je zadat přesně.

Firmy

  1. Otevřete Firmy pro ABRA a klikněte na Přidat firmu.
  2. Kód firmy zkopírujte z adresy webové verze ABRA Flexi: po přihlášení uvidíte v URL část /c/kod_firmy/ (např. .../c/mojefirma/...). Stejný kód používá i REST API.
  3. Název je popisek pro váš přehled; doporučujeme použít oficiální název společnosti, aby šel snadno odlišit.

Typy dokladů

  1. Nejprve mějte přidanou firmu, pro kterou typ vytváříte.
  2. V ABRA Flexi otevřete číselník Typy dokladů v dané firmě (lze jej vyhledat přes vyhledávání nebo menu Nastavení).
  3. Otevřete konkrétní typ (např. Faktura přijatá) a zkopírujte pole Kód / Zkratka. Stejná hodnota je vidět i v URL detailu typu dokladu.
  4. V EasyFlex vyberte firmu, nastavte Směr (faktura-prijata pro dodavatelské faktury, faktura-vydana pro odběratelské) a vložte název i kód přesně tak, jak je v ABRA Flexi.
  5. Uložte typ. Při importu se pak tento kód automaticky nabídne pro vybranou firmu a směr.

Časté otázky

Nemám účet nebo jsem zapomněl heslo, co dělat?
Registrace i obnova hesla se řeší výhradně přes administrátora na {{ contact_email }} nebo {{ contact_phone }}. Samoobsluha zatím není dostupná.
Nenačítá se mi QR kód pro platbu, co dělat?
Zkontrolujte, zda jste přihlášeni. QR kód je dostupný jen po přihlášení v sekci Kredity. Pokud problém přetrvá, napište nebo zavolejte na kontakty níže.
Nemám dostatek kreditů, ale potřebuji rychle zpracovat faktury.
Dočasně odeberte některé PDF a spusťte zpracování menšího počtu souborů. Současně můžete dobít minimálně 100 kreditů (50 Kč) převodem; variabilní symbol a QR kód jsou v sekci Kredity.
Import do ABRA Flexi hlásí chybu ověření.
Ověřte přihlašovací údaje k ABRA Flexi (server, port, uživatel, heslo) a že je správně zvolená firma i kód typu dokladu. Pokud používáte vlastní certifikát, ověřte, že je server dostupný a volba ověřování TLS odpovídá jeho nastavení.
Co se stane, když je faktura prázdná nebo nečitelná?
Prázdné výsledky neodečítají kredity. Pokud je text nečitelný, zkuste lepší sken nebo kontaktujte podporu.
Jak funguje označování řádků pro import?
Každý řádek má přepínač. Jen označené řádky se odešlou do ABRA Flexi. Před importem můžete hodnoty upravit a změny uložit.
